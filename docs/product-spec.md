# 产品规格：专利申请文件起草助手

## 1. 产品定位

**"有证据来源、会主动补问、可审校和回溯的中国专利申请文件起草助手"**

- 部署入口：`vibing.paymond.me/patent`
- 本地优先：专利材料、API Key、历史项目均在用户本机；公网仅分发 Web 静态资源。
- 输出物：**专利申请文件草案包**（摘要、摘要附图、权利要求书、说明书、说明书附图/附图补充清单、支持矩阵与风险审阅报告），而非"说明书"单一文件。

### 明确不是

| 不是 | 原因 |
|------|------|
| 自动保证授权 | 授权取决于新颖性/创造性/审查员判断，产品只能降低形式与公开不充分等风险 |
| 自动专利代理师 | 最终文件需申请人/代理师审阅 |
| 一次性全文生成器 | 分阶段生成、逐阶段确认 |
| 全面新颖性检索工具 | 互联网研究默认关闭、有限度补充，不做 FTO/检索报告 |
| 自动申报工具 | 不接电子申请系统 |
| 授权概率预测 | 无可靠依据，禁止显示概率分数 |

## 2. 需求修正清单（相对原始需求）

| # | 原始需求 | 修正 | 原因 |
|---|----------|------|------|
| 1 | 以"专利申请通过为目标"生成说明书 | 以"降低形式缺陷、公开不充分、权利要求缺乏支持、术语/附图不一致风险"为目标生成草案包 | 授权不可承诺 |
| 2 | API Key 只存浏览器本地，清浏览器即失效 | Key 存 OS Keychain（macOS/Windows/Linux），提供删除与临时会话模式；浏览器只持短期配对 token | DeepSeek 条款禁止浏览器暴露 Key；浏览器存储易被 XSS/扩展读取 |
| 3 | 2023 版指南作为唯一规则 | 版本化规则包：2023-baseline + 2026-01-01（CNIPA 2025 修改，2026-01-01 施行），每条规则带来源/章节/版本 | 规则会更新 |
| 4 | 输出"专利说明书" | 输出"专利申请文件草案包"（含权利要求书/摘要/附图/审阅报告） | 权利要求书才是保护范围核心 |
| 5 | LLM 生成附图 | 仅自动生成框图/流程图/拓扑/简单状态图（确定性 SVG/Mermaid/Graphviz）；机械图/电路图输出 Drawing Brief 请用户上传 | DeepSeek 无图像生成；自由生成图不符合专利附图规范 |
| 6 | 说明书正文含免责声明 | 正文不含 AI 声明；AI 辅助标识放 UI/导出清单/审阅报告/项目元数据 | 申请文件正文洁净 |
| 7 | ChatGPT subscription 作为 LLM 来源（MVP） | 仅预留 CodexLocalProvider 接口，MVP 不实现 | 登录态集成复杂度高 |
| 8 | 免费 Cloudflare 保证大陆可达 | 不承诺；提供境内托管+ICP 迁移文档与真实大陆网络抽样 | Cloudflare 免费版大陆可达性不稳定 |

## 3. MVP 范围

### 支持

- 专利类型：实用新型（正式）、发明专利（Beta）。
- 技术领域：机械、电子、通信、IoT、控制系统、简单软硬结合发明。
- 材料格式：DOC、DOCX、PDF、扫描 PDF、TXT、Markdown、PNG、JPEG；多附件。
- 输出：上述草案包各文件 + 加密项目包（.patentpack）导入导出。

### 不支持（MVP）

- 外观设计、化学/药品/生物/中药、复杂医疗、PCT、审查意见答复、自动申报、授权概率预测。
- ChatGPT subscription 作为 LLM 来源（仅接口预留）。

## 4. 核心用户流

```text
新建项目 → 上传/粘贴交底材料（多附件） → 解析（本地） → 充分性报告
  → Intake 问询（用户逐项回答） → 保护策略确认 → 权利要求骨架 → 逐段起草
  → 附图任务确认 → 摘要 → 审校（支持矩阵/一致性/形式规则） → 审阅 → 导出/存档
```

每次模型生成：可预览将发送内容、可取消、结果缓存、不静默覆盖用户编辑；可回溯每个快照（provider/model/promptVersion/rulePackVersion）。

## 5. 关键 UX 原则

- 克制、精炼、专业；一次一个主任务；编辑阶段才三栏。
- 非聊天机器人式主界面（不采用对话气泡流）；问询以结构化表单呈现。
- 状态可视化：管线阶段、证据来源徽标（source_backed / user_confirmed / external_context / unsupported）、审校红黄绿。
- 异常状态全覆盖：无 Bridge、Bridge 断开、解析失败、模型失败、离线、Key 失效。
