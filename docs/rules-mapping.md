# 规则包结构与 CNIPA 规则映射

## 1. 规则包结构

```text
packages/rules-cn/
  2023-baseline/
    common.json           # 通用（名称/章节/摘要/术语/一致性）
    invention.json        # 发明专利（方法/产品/客体/创造性表述规范）
    utility-model.json    # 实用新型（产品客体/附图要求/创造性表述差异）
    computer-program.json # 计算机程序/软硬结合
    ai-related.json       # AI 相关发明
  2026-01-01/             # CNIPA 2025 修改、2026-01-01 施行（待官方文本核对）
    （同上结构）
```

每条规则：

```json
{
  "ruleId": "UM-FIG-001",
  "patentType": ["utility_model"],
  "severity": "error",
  "deterministicCheck": "figuresRequired",
  "sourceDocument": "专利审查指南（2023）",
  "sourceSection": "第一部分第二章 说明书附图",
  "effectiveFrom": "2023-01-01",
  "effectiveTo": null,
  "userMessage": "实用新型专利申请必须有附图",
  "remediation": "为实用新型补充说明书附图"
}
```

## 2. 确定性规则目录（MVP）

| ruleId | 规则 | 检查方式 |
|--------|------|----------|
| COM-TITLE-001 | 名称不超过 25 字（发明/实用新型名称提醒） | 字符计数 |
| COM-TITLE-002 | 名称不得含"系统/装置/方法"之外的宣传词 | 词表匹配 |
| COM-SECT-001 | 说明书章节齐全（技术领域/背景/内容/附图说明/实施方式） | 章节解析 |
| COM-SECT-002 | 摘要 ≤ 300 字（实用新型/发明） | 字符计数 |
| COM-SECT-003 | 摘要不得含宣传语/噪声 | 词表 + LLM 复核 |
| COM-TERM-001 | 术语全篇一致（同义替换检测） | 术语表 + 比对 |
| COM-REF-001 | 附图标记双向一致（说明书↔附图） | 标记提取比对 |
| COM-REF-002 | 图号连续且附图说明与图一一对应 | 图号解析 |
| COM-REF-003 | 权利要求中附图标记使用规范（实用新型可标注） | 格式校验 |
| INV/UM-OBJ-001 | 客体符合（实用新型：产品结构/形状/构造；发明：方法或产品） | 权利要求语法分类 |
| UM-FIG-001 | 实用新型必须有附图 | 附图存在性 |
| UM-CLAIM-001 | 独立权利要求仅限产品型（实用新型） | 语法分类 |
| CLAIM-IND-001 | 至少一条独立权利要求；从属引用关系合法（引用在前、不得循环、多项引用多项限制） | 引用图分析 |
| CLAIM-SUP-001 | 每条特征在说明书中能找到支持 | 特征-章节比对（LLM+规则） |
| CLAIM-SUP-002 | 说明书不得超出原始记载（交底）范围 | 增量比对 |
| INV-ALGO-001 | 算法类权利要求需与技术特征结合（软硬结合） | 结构检查 |
| AI-INV-001 | 发明人须为自然人；AI 不得列为发明人 | 表单校验 |
| AI-INV-002 | AI 辅助生成需人工审阅确认标识 | 元数据检查 |
| COM-EFFECT-001 | 有益效果与技术特征对应（不得无依据断言） | 支持矩阵 |
| COM-NOISE-001 | 正文无页脚/模板残留/宣传语/外部领域内容 | 噪声词表 + LLM |

## 3. 规则来源与版本管理

- 2023-baseline：以 2023 版《专利审查指南》文本为准（本机缺 PDF，待官方文本核对后填充 sourceSection 精确引用）。
- 2026-01-01：需要 CNIPA 官方公布文本核对（2025 年修改、2026-01-01 施行）；核对后生成差异报告（新增/修改/废止规则）。
- 每版规则包带 rulePackVersion + 来源清单 + effectiveFrom/To。

## 4. 规则校验双轨

1. **确定性检查**（代码实现）：可机器判断的格式/结构/引用/存在性规则。
2. **LLM 复核**：语义类（术语一致性、支持关系、客体判断）作为辅助，结果仍须通过确定性约束门禁。
