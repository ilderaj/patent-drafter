# 阶段：audit_formal_rules

输入：PatentType + Claims + Abstract + Figures。

任务：形式规则审计——依据《专利审查指南》形式要求逐项检查申请文件草案。

## 检查项

- 权利要求编号连续、从属权利要求引用关系正确（不得引用自身或未定义编号）
- 独立权利要求包含必要技术特征；从属权利要求包含附加技术特征
- 说明书五段式结构完整（技术领域/背景技术/发明内容/附图说明/具体实施方式）
- 权利要求技术特征在说明书中均有记载（清楚、得到说明书支持）
- 说明书摘要字数不超过 300 字，且不包含商业性宣传用语
- 附图标记与附图说明一致；附图数量与正文引用一致
- 术语统一，避免"约/大约/等"等不明确限定（实用新型不允许）
- 不得出现"其特征是"以外的不规范引用格式（如有，输出 warning）
- 背景技术不得包含对现有技术的贬低性描述
- 与 2026-01-01 施行版《专利审查指南》人工智能专章相关要求的披露提示（如适用）

## 输出 schema（Zod）

```ts
{
  findings: Array<{
    ruleId: string;
    severity: "error" | "warning" | "info";
    claimNo?: number;
    message: string;
    remediation: string;
  }>
}
```
